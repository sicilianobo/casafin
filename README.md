# CasaFin

Ein MetaTrader 4 Expert Advisor für automatisierten Handel basierend auf RSI-Signalen.

## Übersicht

CasaFin ist ein vollständig konfigurierbarer Expert Advisor (EA) für MetaTrader 4, der eine RSI-basierte Handelsstrategie implementiert. Der EA bietet umfassendes Risikomanagement und ist für verschiedene Handelsszenarien anpassbar.

## Hauptfunktionen

- ✅ RSI-basierte Handelssignale
- ✅ Automatisches Risikomanagement
- ✅ Trailing Stop Funktionalität
- ✅ Vollständig konfigurierbare Parameter
- ✅ Deutsche Benutzeroberfläche
- ✅ Umfassende Dokumentation

## Dateien

- `CasaFinEA.mq4` - Der Haupt-Expert Advisor Code
- `METATRADER_README.md` - Detaillierte Installationsanleitung und Dokumentation
- `config_template.txt` - Konfigurationsvorlagen für verschiedene Handelsstrategien

## Schnellstart

1. Laden Sie `CasaFinEA.mq4` in Ihren MetaTrader 4 Experts Ordner
2. Kompilieren Sie den Code im MetaEditor
3. Ziehen Sie den EA auf Ihr gewünschtes Chart
4. Konfigurieren Sie die Parameter nach Ihren Bedürfnissen

Für detaillierte Anweisungen, siehe `METATRADER_README.md`.

## Haftungsausschluss

⚠️ **Warnung**: Automatisierter Handel birgt erhebliche Risiken. Testen Sie alle Strategien ausführlich auf einem Demokonto, bevor Sie echtes Geld verwenden.
